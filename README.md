# video-gen

Automated video generator prototype. Give it a topic, get back a raw mp4 — real footage / images, voiceover, captions, music where possible.

**Timebox:** 2 hours, start to stop. First commit is the start-of-timer marker; final commit is the stop.

## The brief

> Build a prototype of an automated video generator. Give it a topic, get back a raw mp4. Real footage, images, voiceover, captions, music, whatever you can make it do in the time. The more it does on its own, the better.
>
> Total freedom on how. Any language, any framework, any APIs, any AI tools, no-code or full code. Build it the way you would actually build it if this were your job.
>
> It does not need to be finished or pretty. A rough mp4 that shows what you can automate is exactly what we want.
>
> Two hours, max. Then hand it over.
